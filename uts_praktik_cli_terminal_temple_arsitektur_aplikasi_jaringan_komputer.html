STAGE_01 // DIRECTIVES

Instruksi Ujian Peserta UTS

0 / 5 Tahap Selesai
01

Membuat Folder AJK-Nama Mahasiswa

Peserta UTS wajib membuat sebuah direktori/folder baru pada Terminal Temple dengan format penamaan AJK-Nama Mahasiswa, kemudian masuk ke dalam direktori tersebut.

$ mkdir "AJK-Nama Mahasiswa" && cd "AJK-Nama Mahasiswa"
02

Membuat File Profil-Nama Mahasiswa.txt di Dalam Folder

Di dalam direktori AJK-Nama Mahasiswa yang telah dibuat, peserta UTS membuat file teks bernama Profil-Nama Mahasiswa.txt.

$ touch "Profil-Nama Mahasiswa.txt"
03

Mengisi File dengan Tujuh (7) Informasi Profil Peserta UTS

Tuliskan 7 baris informasi profil peserta UTS ke dalam file Profil-Nama Mahasiswa.txt menggunakan perintah pengisian teks CLI (echo / cat > / editor terminal). Lihat rincian 7 informasi profil pada panel di sebelah kanan.

04

Menuliskan Seluruh Command CLI yang Digunakan

Catat dan rekap seluruh urutan perintah (command) yang Anda jalankan dari awal pembuatan direktori, pengisian 7 data profil, hingga verifikasi isi file untuk dilampirkan pada formulir pengumpulan ujian.

05

Mengumpulkan Bukti Hasil Ujian (ls, cat, pwd)

Ambil tangkapan layar (screenshot) sebagai bukti hasil ujian yang memperlihatkan eksekusi perintah ls, cat, dan pwd, lalu unggah ke formulir Tally resmi.

STAGE_02 // EXAM_PROTOCOL

Ketentuan Pengerjaan Peserta UTS

  • > Setiap peserta UTS wajib menggunakan nama asli masing-masing pada penamaan folder AJK-Nama Mahasiswa dan file Profil-Nama Mahasiswa.txt.
  • > Seluruh proses pembuatan direktori, pembuatan file, dan pengisian 7 informasi profil dilakukan murni melalui antarmuka baris perintah (CLI Terminal Temple).
  • > Bukti hasil ujian berupa screenshot wajib terlihat jelas, utuh, dan tidak terpotong pada bagian perintah maupun output terminalnya.
  • > Pastikan daftar seluruh command yang ditulis sesuai dengan yang tampak pada tangkapan layar bukti hasil ujian sebelum dikirim melalui Tally Form.

7 Informasi Profil di Dalam File

Isi file Profil-Nama Mahasiswa.txt wajib memuat tujuh (7) informasi profil peserta UTS berikut:

01. Nama Lengkap
02. Tempat Tanggal lahir
03. Status
04. Pekerjaan
05. Film Favorit
06. Kata Kata Motivasi
07. Cita-cita/Impian
